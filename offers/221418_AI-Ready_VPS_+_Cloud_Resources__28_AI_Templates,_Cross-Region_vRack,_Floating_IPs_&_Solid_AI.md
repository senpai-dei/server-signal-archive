☁️ **CLOUD RESOURCES**  
━━━━━━━━━━━━━━━━━━━━━━

Cloud Resources takes a different approach from ordering individual VPS plans.

You purchase a pool of resources and divide it between VMs however you want.

For example, our $25/mo Flex Starter pool includes:

• 8 pooled vCPU  
• 8 GB pooled RAM  
• 100 GB storage  
• 4 public IPv4  
• Up to 4 VMs  
• 8 TB public bandwidth  
• 1 TB private vRack bandwidth

From the same resource pool you can build multiple VMs and choose between available Intel, AMD Ryzen and AMD EPYC infrastructure.

And those VMs don't have to live in the same location.

🌎 **CROSS-REGION PRIVATE vRACK**

One of the features we've spent a lot of time developing is private networking.

VMs can communicate through an isolated private vRack either:

• within the same location  
• or across supported regions

So you can build infrastructure such as:

[ Ryzen VM — Dallas ]  
│  
Private vRack  
│  
[ Intel VM — Europe ]

without sending that communication over the public Internet.

🔄 **FLOATING IPs**:

Cloud Resources also supports Floating IPv4 addresses between eligible VMs within the same region.

Move an IP between VMs without changing the public address used by your application.

🔥 **FIREWALL + NETWORK MANAGEMENT**

Directly from Solid Panel you can also:

• Create inbound/outbound firewall rules  
• TCP / UDP / ICMP filtering  
• Port ranges  
• CIDR filtering  
• Set PTR/rDNS  
• Allocate IPv4 addresses  
• Monitor public bandwidth  
• Monitor private vRack bandwidth  
• Deploy custom ISOs  
• Configure backups  
• Rebalance resources between VMs

🤖 **AND THEN THERE'S SOLID AI**

Cloud Resources also integrates with Solid AI.

Instead of manually building every part of an environment, you can describe what you're trying to build and let Solid AI help organize the deployment.

For example:

"Build me two VMs in different regions connected through a private vRack."

or

"Create an AI server with the resources needed for Ollama and Open WebUI."

The goal is to make deploying infrastructure easier for both experienced users and customers who don't want to spend hours configuring everything manually.
